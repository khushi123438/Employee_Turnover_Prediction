# 👨‍💼 Employee Turnover Prediction using ML

A simple Machine Learning project to predict employee turnover using employee data and classification algorithms.

## 📂 Project Files
- `employee_turnover.ipynb` - ML model code
- `dataset.csv` - Dataset used for training and testing

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn

## 🤖 Algorithm Used
- Logistic Regression

## ▶️ How to Run

Install dependencies:

pip install pandas numpy scikit-learn

Run the notebook or python file to train the model and predict employee turnover.
